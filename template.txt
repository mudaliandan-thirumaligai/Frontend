🏠 3. Landing Page Layout (Modern + Spiritual)

Here’s the final recommended design:

🔷 Section 1 — Hero Banner

Calm blue–indigo gradient

Image of Sri Mudhaliandan Swamy (blurred or softly faded behind text)

Title (White, glowing):
"Sri Mudhaliandan Swamy Thirumadapalli"

Subtitle:
A sacred lineage dedicated to dharma, kainkaryam, and spiritual guidance.

Buttons

“Learn More”

“Upcoming Events”

“Contribute / Donate”

Animations

Soft fade-in title

Slow parallax background

Button hover glow

🔷 Section 2 — About Organization

Two-column:

Left: image of temple/swamiji

Right: clean text

Fade-in on scroll.

🔷 Section 3 — Upcoming Events

Grid of event cards with:

Date

Title

Location

“View More”

Cards have hover zoom animation.

🔷 Section 4 — Media Highlights

Show small previews:

3 images

1 video preview

1 audio clip

1 book cover

Each card can link to full respective page.

🔷 Section 5 — Gallery Preview

A horizontal carousel slider with:

Festival photos

Swami visits

Annadhanam images

Use subtle motion + snap scrolling.

🔷 Section 6 — Leadership

Picture + Name + Small description of Acharya.

Soft fade-in.

🔷 Section 7 — Location & Contact

Show a clear location map (Google Maps Embed).
Contact form with:

Name

Email

Message

🔷 Section 8 — Footer

Organization name

Quick links

Social media icons

Copyright

Modern, minimal, blue-gray background.

🌗 6. Light & Dark Mode Design
Light Mode

White backgrounds

Indigo-blue accents

Subtle shadows

Dark Mode

Deep navy backgrounds

Indigo highlights

Soft gold text-accent for spiritual feel

Use CSS variables:

:root {
  --bg: #ffffff;
  --text: #1a1a1a;
  --primary: #3B5BA9;
}

.dark-mode {
  --bg: #0C0F16;
  --text: #EAEAEA;
  --primary: #8FA8FF;
}


Toggle with a button in navbar.
