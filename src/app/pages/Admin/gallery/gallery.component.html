How to link photos to an event
  1. Tick the photos you want to link. You can pick photos from different uploads, and use Select page or Select all for many at once. Tip: use the "Not linked to an event" filter to find the ones still left.
  2. Press Link to Event in the bar that appears.
  3. Choose Existing event (filter by year and month, then pick it) or + New event (fill in the name and dates).
  4. Press Link photos (or Create event & link). Linked photos show up in that event's gallery.
  5. Linked by mistake? Tick the photos and press Unlink. The photos stay in the gallery.

Right after you upload photos, a prompt also appears so you can link that batch straight away.
